# 實驗 3：鏡頭角度增強 v2000（h2000 配方＋`--view-aug 0.5`）

> 2026-11-15｜Kaggle 單張 P100｜數字在 `metrics.json`、`docs/viewbench/20261115-v2000n_smooth9.json`

## 做法

訓練時一半樣本把整副骨架繞肩膀中點在 3D 隨機轉 yaw ±45°、pitch ±20°，再投影回 2D（和 `scripts/viewbench.py` 同一個函式）。其他和上線的 h2000 完全相同。

## 鏡頭角度（ASL Citizen test 隨機 4,000 支，換人，整段 top-1）

| 鏡頭角度 | h2000 | v2000 |
| --- | --- | --- |
| 正面 0° | 83.8% | 81.1% |
| 左右 ±15° | 55／52% | **81／80%** |
| 左右 ±30° | 17／16% | **80／78%** |
| 左右 ±45° | 4／2% | **76／74%** |
| 上／下 20° | 31／22% | **79／78%** |

## 正面驗收（同門檻 0.41）

| 指標 | h2000 | v2000 |
| --- | --- | --- |
| 換人 holdout 整段 top-1 | **82.9%** | 80.5% |
| 換人 顯示正確 | **92.7%** | 91.1% |
| 換人 第一個就對 | **70.7%** | 69.4% |
| 沒輸出 | 23.7% | 23.9% |
| 詞彙表外誤報 | **22.7%** | 26.0% |
| WLASL test top-1 | 50.1% | 50.1% |
| WLASL 驗證 top-1（Kaggle，n／bg） | 46.1／46.5% | 44.3／45.8% |

v2000 自己調出的門檻是 0.42：換人顯示正確 91.2%，仍然達到 ≥90% 的標準。

## 判讀

- 角度的弱點基本上被補起來了：偏 45° 還有 74～76%，h2000 只有 2～4%。
- 代價是正面少 2.4 點、詞彙表外誤報多 3.3 點：模型要把容量分去容忍角度。
- **注意：這個角度測試偏樂觀。** 測試用的轉法和訓練增強是同一個函式，等於考題和練習題同一型。真實鏡頭換角度時，還有遮擋、MediaPipe 深度誤差、側面手指看不清楚等問題，這些模擬不出來。真正的答案要靠真實鏡頭實測。

## 結論

等用戶決定是否上線，以及用真實鏡頭在不同位置實測。
