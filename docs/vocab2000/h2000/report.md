# 實驗 1：慣用手統一＋手部局部座標（h2000）vs k2000

> 2026-11-14｜模型 `models/20261114-h2000n`、`models/20261114-h2000bg`（不進 git，含 ASL Citizen 訓練，不公開、不商用）｜數字在 `metrics.json`

## 改了什麼

- `--canon`：以單手移動量判斷主手，左手為主就整段鏡像成右手為主（在模型內做，ONNX 也包含）。
- `--hand-local`：每隻手多一組以手腕為原點、手掌大小為單位的座標。
- 其他設定、資料、驗收流程和 k2000 完全相同。門檻重調後為 `min_confidence` 0.36、`spot_threshold` 0.78。

## 結果

### 換人：ASL Citizen test 驗收那一半（P9、P17、P22、P42、P48，6,426 支）

| | k2000 | **h2000** |
| --- | --- | --- |
| 整段 top-1／top-5 | 80.7%／94.9% | **82.9%**／95.8% |
| 上線解碼器：有輸出時正確 | 92.5% | 91.8% ✅ ≥90% |
| 上線解碼器：第一個詞正確 | 68.5% | **73.1%** |
| 上線解碼器：沒有輸出 | 25.9% | **20.3%** |

- 同樣門檻 0.40 比較：h2000 顯示正確 92.5%、涵蓋率 77.6%。k2000 在 0.41 時是 92.0%／74.2%，所以在相同精確率下能多輸出約 3 點。
- 11 位全部合計：top-1 81.1% → 83.0%。

## 結論

- 換人 top-1 +2.2、第一個詞正確 +4.6、沒輸出 −5.6，顯示正確率維持在 90% 以上，達到上線條件。
- 代價：門檻較低，詞彙表外誤報多約 2 點（統計上不顯著）。

## 同門檻比較與上線（2026-11-14）

tune 自己選的 0.36 會讓顯示正確率和詞彙表外誤報看起來變差，這是門檻較低造成的，不是模型變差。改成和 k2000 同樣用 0.41／0.78 比較：

| | k2000 | **h2000 @0.41** |
| --- | --- | --- |
| 換人 top-1 | 80.7 | **82.9** |
| 顯示的詞正確 | 92.5 | **92.7** |
| 第一個詞正確 | 68.5 | **70.7** |
| 沒有輸出 | 25.9 | **23.7** |
| 詞彙表外誤報 | 23.7 | **22.7** |
| WLASL top-1 | 49.3 | **50.1** |
| WLASL 顯示的詞正確 | 61.5 | 61.1（約差 3 支，在誤差內） |

- 已上線：h2000n／h2000bg 是 `models/` 最新的資料夾，`serving.json` 改成 0.41／0.78。後端測試 17 個全過。
- 退回 k2000：設 `WLASL_MODEL_DIR=models/20261113-k2000n`、`WLASL_SPOT_MODEL_DIR=models/20261113-k2000bg`。

## 實驗 1b：每隻手轉正到自己的座標系（r2000，未採用）

- 手部局部座標再旋轉，讓手腕→中指根固定朝上，轉角另給 cos/sin（`--hand-rot`），其他和 h2000 相同。
- 同門檻 0.41：換人 top-1 81.9（h2000 是 82.9），WLASL 48.9（50.1），只有詞彙表外誤報較低（21.3 vs 22.7）。逐人看，11 位裡有 8 位變差或持平。
- 推測：手腕方向本身就是 ASL 手勢的一部分，轉正把它從手指座標裡拿掉，模型得從 cos/sin 重新組回來，可能反而更難學（沒有另做實驗確認）。數字在 `docs/vocab2000/r2000/metrics.json`。
