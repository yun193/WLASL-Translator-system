# 詞彙擴充到 2000 詞（k2000n＋k2000bg）：換人單字 top-1 81%，顯示的詞 92.5% 正確

> 2026-11-13｜模型 `models/20261113-k2000n`、`models/20261113-k2000bg`（不進 git）｜數字在 `metrics.json`
>
> 這兩個模型混了 ASL Citizen（Microsoft Research License，只限非商業研究）訓練，**不公開、不商用**。

## 改了什麼

- 設定和 a2000 相同，資料是 WLASL2000 加上 ASL Citizen train＋val。差別有兩點：
  - 用 2000 類的 val 挑最好的 epoch。
  - 匯出完整的 2000 詞，不再只留前 100 類。
- 門檻改成跟著模型走：寫在 `models/<n>/serving.json`，由 `scripts/vocab2000.py tune` 產生。
  - 2000 詞版：`min_confidence` 0.41、`spot_threshold` 0.78。
  - 100 詞版沒有 serving.json，維持 0.5／0.78。

## 驗收方法

- 測試資料：ASL Citizen test 中和 WLASL2000 同名的 1,159 詞，共 14,121 支，來自 11 位沒進訓練的手語者。
- 依手語者對半分：
  - 調門檻：P6、P15、P18、P35、P47、P49。
  - 驗收：P9、P17、P22、P42、P48。
- 調門檻時，要求顯示的詞與高信心預測都 ≥91%（目標 90% 再加 1 點餘裕），在這個條件下挑「第一個詞正確」最高的組合。
- 驗收那一半完全沒有參與調門檻。

## 結果

### 換人：ASL Citizen test，驗收那一半（5 位、6,426 支）

| | 2000 詞（k2000） |
| --- | --- |
| 整段 top-1／top-5 | **80.7%**／94.9% |
| 信心 ≥0.41 的涵蓋率 | 74.2% |
| 信心 ≥0.41 時正確 | **92.0%**（91～93） |
| 上線解碼器：有輸出時正確 | **92.5%**（92～93）✅ ≥90% |
| 上線解碼器：第一個詞正確 | 68.5% |
| 上線解碼器：沒有輸出 | 25.9%（其中 76% 的正確答案落在前 3 名） |

- 11 位手語者全部合計：top-1 81.1%，顯示的詞 91.9% 正確。
- 逐人看：
  - 整段 top-1 在 74～91% 之間，顯示的詞正確率在 88～95% 之間。
  - 最差的是 P6：顯示的詞 87.9% 正確，第一個詞正確 61%。
- 只有 P15 一位會在一支單字影片裡冒出多個詞，共 333 支，其他人幾乎是 0。這是 P15 的錄法造成的，不是模型問題。
- 逐詞看換人 top-1：中位數 85%。最差的 10% 詞在 57% 以下，例如 truth、safe、brave、print、hug。

### 最常見的錯誤：多半是 ASL 本來就很像，或是同義詞

brave→health（11）、hurt→pain（10）、hug→love（9）、list→lesson（9）、bright→clear（8）、print→newspaper（8）、best→better（8）、assistant→assist（8）、murder→kill（8）、bathroom→toilet（7）

這類錯誤很多是同一個手勢或只差一點點，WLASL 本身也把它們分成不同類。這不只是模型的問題，要靠上下文或合併同義類才能解決。

### 對照：WLASL 2000 類 test（1,414 支／1,189 類，看過的人、網路影片）

| | k2000n | k2000bg | 雙模型＋上線門檻 |
| --- | --- | --- | --- |
| 整段 top-1 | 45.3% | 48.3% | 49.3% |
| 顯示的詞正確 | | | **61.5%** |

- WLASL 2000 類是學術界公認很難的基準，每類只有幾支影片，比法和拍攝條件也很雜。pose 類方法一般就在三到五成。
- **重點**：遇到不像 ASL Citizen 的影片時（網路影片、不同拍法），顯示的詞只有約六成正確。門檻是用 ASL Citizen 調的，換到這類影片就會偏寬。

### 詞彙表外誤報（WLASL2000 完全沒有的詞，300 支）

報出一個詞的比例是 **23.7%**（19～29）。a2000 的 100 詞版是 13.7%。

詞彙變多以後，任何手勢都比較容易「像」某個詞，加上門檻比 0.5 低，所以亂認變多了。

## 上線（2026-11-13，用戶決定直接全面換成 2000 詞）

- 已把 k2000n 設成 `models/` 裡最新的資料夾、k2000bg 設成最新的背景類模型。
  - 確認過 `config.MODEL_DIR`＝k2000n、`SPOT_MODEL_DIR`＝k2000bg，`MIN_CONFIDENCE`＝0.41、`SPOT_THRESHOLD`＝0.78。
- 後端測試改成只用本機有的參考影片，17 個全過。
- 要退回 100 詞版：設 `WLASL_MODEL_DIR=models/20261113-a2000n`、`WLASL_SPOT_MODEL_DIR=models/20261113-a2000bg`，門檻會自動回到 0.5／0.78。

## 還沒量的

- 連續比劃（spotgate 合成連續、podcast、YouTube）在 2000 詞下的誤報。窗口門檻刻意只往保守方向挑（0.78 以上）。
- 用戶本人用前鏡頭實測，這是最重要的一項：上面的 WLASL 對照顯示，換拍攝條件後正確率會掉。
- 注意：舊模型的評估腳本現在也會讀上線模型的 serving.json。比較舊模型時，要明確設 `WLASL_MIN_CONFIDENCE`。
