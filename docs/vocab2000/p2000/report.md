# 實驗 2：仿 Uni-Sign 分部位 GCN 編碼器 p2000（未採用）

> 2026-11-15｜`--arch parts`｜Kaggle 單張 P100｜數字在 `metrics.json`、`docs/viewbench/20261115-p2000n_smooth9.json`

## 做法

照 Uni-Sign（ICLR 2025）的姿勢分支：左手、右手、上半身各自用 3 層空間 GCN 編碼（手用部位內局部座標），再接時間卷積，三部位特徵串起來餵原本的 Transformer。沒有移植 mT5 語言模型和大規模預訓練。

## 結果（同門檻 0.41，和上線的 h2000 比）

| 指標 | h2000 | p2000 |
| --- | --- | --- |
| WLASL 驗證 top-1（Kaggle） | 46.1% | 37.9% |
| 換人 holdout 整段 top-1 | **82.9%** | 75.1% |
| 換人 顯示正確 | **92.7%** | 89.3% |
| 換人 第一個就對 | **70.7%** | 61.9% |
| 詞彙表外誤報 | 22.7% | 21.7% |
| WLASL test top-1 | **50.1%** | 40.5% |
| 鏡頭偏 ±15° top-1 | **55／52%** | 25／24% |
| 鏡頭上／下 20° top-1 | **31／22%** | 9／5% |

全面變差，鏡頭角度更怕偏。

## 判讀

- Uni-Sign 的分數主要來自大規模預訓練和語言模型；論文消融中只換掉語言模型、改用分類頭，MSASL 就從 77.9 掉到 56.9。只搬 GCN 編碼器，拿不到那部分好處。
- 部位內局部座標讓手形更細，但丟掉了手和身體的相對位置（只剩出現旗標和全身 xy 一起被壓成一個向量），而 2000 詞裡很多詞只差在手的位置。
- 模型容量差不多（86 萬對 84 萬參數），train loss 也接近，所以不是訓練不夠，是表示方式不適合這個資料量。

## 結論

不採用，上線維持 h2000。下一步：實驗 3 在 h2000 配方上加 `--view-aug`。
