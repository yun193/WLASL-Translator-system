# ASL Citizen test：新使用者在家用鏡頭的單字正確率

> 2026-11-12｜工具 `scripts/aslcbench.py`｜數字在 `metrics.json`；影片與關鍵點在 `data/aslcitizen/`（不進 git，Microsoft Research 授權只限非商業研究）
>
> 全程用上線設定與上線模型（w2000n＋w2000bg 平均、門檻 0.5、解碼器），沒有針對這批影片調參。

## 結論先講

**換成新的人、家用鏡頭，整段分類 top-1 是 68%，比同一批詞在 WLASL 的 86% 低 18 點；但高信心的輸出仍有 92% 是對的。** 主要問題是模型變得常常沒把握：上線解碼器有 45% 的影片沒有輸出確定的詞，介面只會顯示 `?(前 3 名)`。

| | ASL Citizen（11 位新手語者） | WLASL 同詞（看過的人） |
| --- | --- | --- |
| 整段 top-1 | **559/819＝68.3%（65～71）** | 49/57＝86.0%（75～93） |
| 整段 top-5 | 85.5%（83～88） | 94.7% |
| 信心 ≥0.5 的涵蓋率 | **54.2%** | 78.9% |
| 信心 ≥0.5 時正確 | **91.7%（89～94）** | 95.6% |

範圍：ASL Citizen test 中和 WLASL100 完全同名的 67 詞、819 支影片，11 位手語者都沒進任何訓練。

## 使用者實際看到的結果（上線解碼器）

| | 比例 |
| --- | --- |
| 第一個詞正確 | 414/819＝50.5%（47～54） |
| 沒有確定的詞（只顯示 `?`） | 366/819＝44.7% |
| 有輸出時正確 | 414/453＝91.4% |
| 一支單字影片冒出多個詞 | 1.6% |

- 有輸出的時候幾乎都對，切詞也沒有出問題（多詞只有 1.6%，沒輸出的比例和整段分類的低信心比例相當）。
- 低信心的 375 支裡，第一名對 40%、**前 3 名含正解 63%**：介面顯示的 `?(前 3 名)` 對使用者還算有參考價值。

## 雙模型平均在新領域幫助更大

| | w2000n 單模型 | 雙模型平均（上線） |
| --- | --- | --- |
| top-1 | 62.3% | **68.3%** |
| 信心 ≥0.5 時正確 | 81.7% | **91.7%** |
| 涵蓋率 | 61.9% | 54.2% |

WLASL 上兩者只差 2～4 點；換到新領域差 6～10 點。之前選雙模型的理由（降低亂認）在這裡得到獨立驗證。

## 門檻的取捨（僅供參考，不據此改門檻）

| 門檻 | 涵蓋率 | 正確 |
| --- | --- | --- |
| 0.3 | 73% | 82% |
| 0.4 | 63% | 89% |
| **0.5（上線）** | 54% | 92% |
| 0.6 | 44% | 95% |

降門檻可以多輸出，但錯誤也會跟著增加，詞彙表外的亂認也會上升（這裡沒量）。真正的解法是讓模型對新的人更有把握，而不是調門檻。

## 每位手語者

正確率從 56% 到 85%（P22 56%、P18 61%、P48 62%，最好的 P15 85%），和 WLASL 換人 4 折看到的分散度類似。手在畫面中被偵測到的幀比例（中位數 ASL Citizen 41%、WLASL 61%）對正確率只有小影響：低於 30% 的影片 64%，其他 69～70%。

常見混淆：cook→all（6 次）、paper→dark、fish→paint、before→letter（各 5 次）、apple→candy、year→right（各 4 次）。year→right 在 YouTube 測試也出現過。有些可能是兩個資料集對同一個英文詞用了不同的比法，沒有逐一檢查。

## 和之前的估計比

- 上次用 WLASL 換人 4 折推估新使用者約 70%，實測整段 68%，**估計大致準確**。
- 論文中 WLASL 訓練的 I3D 在 ASL Citizen 只有 8.5%。我們用關鍵點輸入，加上關鍵點雜訊增強與雙模型，落差小得多。
- 新領域的落差（18 點）比 WLASL 內部換人（8 點）大，代表除了換人，拍攝條件（家用鏡頭、角度、光線、手出畫面）也有影響。

## 下一步建議

**用 ASL Citizen train（35 人）加入訓練**，目標是把新使用者的涵蓋率從 54% 拉高，同時維持高信心時的正確率 ≥90%。驗收看兩把尺：這份 ASL Citizen test（11 人，訓練完全不碰），以及 WLASL 換人 4 折。WLASL2000 同名詞的影片約 20 GB，在 Kaggle kernel 裡直接從微軟抽取。

## 限制

- 只測 67 個完全同名詞；WLASL100 另外 31 個詞在 ASL Citizen 拆成變體，沒有納入。
- WLASL 對照只有 57 支（test 裡屬於這 67 詞的影片），區間寬。
- ASL Citizen 一支影片一個詞，前後有少量靜止。這測的是單字；真實鏡頭還有連續比劃、即時幀率等因素，這份測試沒有涵蓋。
- 詞彙表外的亂認率沒有量（要再抽其他詞的影片）。
